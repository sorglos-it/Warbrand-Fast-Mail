# Warbrand Fast Mail

**Warbrand Fast Mail** makes sending items between your characters fast and effortless.

Create **automated mail rules** that decide which items should be sent to which Warband character. No more manually searching through your bags and entering character names every time.

### ✉️ Features

* ⚡ **Fast automated mailing**
* 📋 **Custom mail rules**
* 👥 Send items directly to **Warband characters / alts**
* 🎯 Rule-based item matching
* 🔄 Quickly repeat your configured transfers
* 🧹 Reduce repetitive mailbox management
* 🎮 Designed for easy use directly inside WoW

### 🚀 Example

Create a rule such as:

`Healing Potions → Alt: MyHealer`

Whenever you want to transfer your potions, **Warbrand Fast Mail** handles the rest.

**Fast. Simple. Automated.**

> Built for players who regularly move items between their characters.
